# SparX Summer 2026 Project
## NERDSwerve
This will serve as the hub for the NERDSwerve build. As a starting point this will be the hub for the documentation and project plans. Specifically we will be building the Super NERDSwerve 3.0 using Neos for the motors.

### Reference
- All STEP/DFX files can be found on the [3D-Printing & Tolerancing](https://www.nerdswerve.com/getting-started/3d-printing-tolerancing) page on the NERDSwerve website.
- All CAD Assemblies can be found on the [CAD & Configurations](https://www.nerdswerve.com/getting-started/cad-configurations) page on the NERDSwerve website.
